# Sharanya Bandi — Portfolio

## Files
- `index.html` — portfolio structure/content
- `style.css` — responsive styling
- `script.js` — mobile menu, theme switcher, scroll animations
- `assets/` — add your images here
- `resume.pdf` — add your actual resume PDF with this filename

## Customize before publishing
1. Replace `your.email@example.com` with your real email.
2. Replace GitHub/LinkedIn URLs with your profiles.
3. Replace project GitHub links with actual repositories.
4. Add your photo if desired.
5. Put your resume in the project folder as `resume.pdf`.
6. Update the internship details with the exact company, role and dates.

## Run locally
Double-click `index.html`, or use VS Code Live Server.

## Publish free
Create a GitHub repository, upload these files, then enable GitHub Pages in the repository's Settings → Pages.
